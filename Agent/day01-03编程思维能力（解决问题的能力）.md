# day1-03编程思维能力（解决问题的能力）

### ▼ 一、编程思维是什么

编程思维（Computational Thinking）不是"写代码的思维"，而是一种解决问题的思维方式。它教你把复杂的大问题，拆解成一个个小问题，然后用计算机能理解的方式来解决。

编程思维主要包括四个方面：

1. **分解（Decomposition）**：把大问题拆成小问题
2. **模式识别（Pattern Recognition）**：找出规律和相似性
3. **抽象（Abstraction）**：抓住重点，忽略无关细节
4. **算法设计（Algorithm Design）**：设计解决问题的步骤

### 二、为什么需要训练编程思维

很多人学编程的困境是：语法都学会了，但遇到实际问题还是不会写代码。这就是缺了编程思维。

* **语法是"字"，编程思维是"作文"**：认识所有字不代表会写文章
* **编程思维是可迁移的**：不仅写代码有用，解决生活中的问题也能用
* **决定了你的上限**：只会语法的是"码农"，有编程思维的才是"程序员"

### 三、怎么训练编程思维

#### ▼ 方法一：拆解问题（最重要）

遇到问题先别急着写代码，先想清楚：
**例子：写一个“猜数字”游戏**

第一步：拆成小问题
1. 电脑随机生成一个 1-100 的数字
2. 让用户输入一个数字
3. 比较用户猜的和答案，告诉用户大了还是小了
4. 重复步骤 2-3，直到猜对
5. 统计猜了多少次

第二步：每个小问题再细化
* 怎么生成随机数？ -> 查 Python 的 random 模块
* 怎么获取用户输入？ -> input() 函数
* 怎么比较？ -> if...else
* 怎么重复？ -> while 循环
* 怎么统计次数？ -> 用一个变量计数

第三步：把步骤翻译成代码

```python
import random

answer = random.randint(1, 100)
count = 0

while True:
    guess = int(input("请猜一个 1-100 的数字："))
    count += 1
    
    if guess == answer:
        print("恭喜你，猜对了！你猜了", count, "次")
        break
    elif guess > answer:
        print("大了，再小一点")
    else:
        print("小了，再大一点")
```

#### ▼ 方法二：流程图法

把解决问题的步骤画成流程图，用图形表示逻辑：
* **开始/结束**：椭圆形
* **处理步骤**：矩形
* **判断**：菱形
* **箭头**：表示流程方向

**例子：判断一个数是不是偶数**

```text
开始
 ↓
输入一个数 n
 ↓
n ÷ 2 余数是 0 吗？
 ├── 是 → 输出"是偶数"
 └── 否 → 输出"是奇数"
 ↓
结束
```

#### ▼ 方法三：伪代码法

先用“人话”把程序逻辑写出来，再翻译成真正的代码。

**伪代码示例：**

```bash
功能：计算从 1 加到 100 的和

初始化 sum = 0
初始化 i = 1
当 i <= 100 时：
    sum = sum + i
    i = i + 1
输出 sum
```

**翻译成 Python：**

```python
sum = 0
i = 1
while i <= 100:
    sum = sum + i
    i = i + 1
print(sum)
```

### 四、新手常见误区

❌ **误区一：上来就写代码**
-> 正确做法：先想清楚逻辑，思路清晰了再写

❌ **误区二：想一步到位写出完美代码**
-> 正确做法：先写能跑的版本，再慢慢优化

❌ **误区三：遇到问题就问人**
-> 正确做法：先自己想 15 分钟，实在不会再查再问

❌ **误区四：只看不练**
-> 正确做法：每学一个概念，马上写 3-5 个小例子
