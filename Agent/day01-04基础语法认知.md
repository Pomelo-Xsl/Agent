# day1-04基础语法认知

Python和Java是目前企业级应用和AI领域最主流的两门语言。虽然它们语法“长相”不同(一个靠缩进，一个靠大括号)，但底层的编程逻辑骨架完全一样。本文分为上下两篇，你可以先选一门主攻，另一门作为对照参考。


## 上篇：Python 基础语法（灵活、简洁、动态）

Python 的设计哲学是“优雅”和“明确”，代码读起来像英文大白话，非常适合初学者建立编程直觉。

### 一、变量与赋值（动态类型）

Python 是动态类型语言：你不需要提前声明变量是什么类型，解释器会在运行时根据赋值自动推断。

```python
# 变量声明 —— 直接用等号赋值，无需提前声明类型
name = "小明"       # 字符串 (str)
age = 25            # 整数 (int)
height = 1.75       # 浮点数 (float)
is_student = True   # 布尔值 (bool), 首字母必须大写 True / False

# 变量可以随时改变类型（动态特性）
age = "二十五"      # 现在 age 变成了字符串类型 (Python允许这样)
```

> 💡 **核心记忆**：等号 `=` 是赋值，意思是“把右边的值放进左边的盒子里”。变量名只能由字母、数字、下划线组成，不能以数字开头。

---

### 二、四种基础数据类型速查

| 类型名称 | 英文名 | 代码示例 | 特征标识 |
| :--- | :--- | :--- | :--- |
| **字符串** | str | `"Hello"` 或 `'World'` | 必须用引号（单双引号都可以）。 |
| **整数** | int | `100` 、 `-5` | 不带小数点的数字。 |
| **浮点数** | float | `3.14` 、 `0.0` | 带小数点的数字。 |
| **布尔值** | bool | `True` 、 `False` | 首字母大写，不加引号，用于逻辑判断。 |

---

### 三、条件判断（if / elif / else）

```python
score = 85

if score >= 90:
    print("优秀")       # 缩进4个空格, 表示属于if
elif score >= 60:
    print("及格")       # 如果score=85, 走这一行
else:
    print("不及格")     # 前面都不满足则走这里

# 【比较运算符】
# == (等于)    != (不等于)    >    <    >=    <=
# 逻辑运算符: and (且)    or (或)    not (非)
```

---

### 四、循环（for / while）

#### 1. for 循环（明确次数或遍历集合）

```python
# 打印 0 到 4
for i in range(5):          # range(5) 生成 0,1,2,3,4
    print(f"当前数字：{i}")

# 遍历列表
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(f"我喜欢吃 {fruit}")
```

#### 2. while 循环（条件驱动，次数不确定）

```python
count = 0
while count < 3:            # 只要条件为True就一直循环
    print("循环中...")
    count = count + 1       # 必须修改条件，否则死循环
```

---

### 五、函数（def）

用 `def` 关键字定义函数，用 `return` 返回结果。

```python
# 【定义函数】
def greet(name):            # name 是参数
    """打招呼函数"""
    message = "你好，" + name
    return message          # 返回值

def add(a, b):
    return a + b

# 【调用函数】
result1 = greet("小红")
print(result1)              # 输出：你好，小红

result2 = add(5, 3)
print(result2)              # 输出：8
```

> 🔥 **Python 特色**：如果函数没有 `return`，默认返回 `None`（相当于“空”）。

## 下篇：Java 基础语法（严谨、规范、静态）

Java 的设计哲学是“严谨”和“稳定”。静态类型意味着你必须明确告诉编译器每个变量是什么类型，这让代码更健壮，但写起来更“啰嗦”。

### 一、变量与赋值（静态类型）

Java 要求先声明类型，再使用。一旦声明为某种类型，就不能赋其他类型的值。

```java
// 变量声明 —— 必须写上类型
String name = "小明";      // 字符串 (String, 注意S大写)
int age = 25;              // 整数 (int)
double height = 1.75;      // 双精度浮点数 (double)
boolean isStudent = true;  // 布尔值 (boolean), 注意是 true/false 全小写

// 类型是锁死的！下面这行会报错（编译不通过）
// age = "二十五";         // 错误: String 不能赋值给 int 变量
```

> 💡 **区别记忆**：Python 用 `True/False`（首字母大写）；Java 用 `true/false`（全小写）。

---

### 二、四种基础数据类型速查

| 类型名称 | 英文名<br>(Java写法) | 代码示例 | 特征标识 |
| :--- | :--- | :--- | :--- |
| **字符串** | String | `"Hello"` | 必须用双引号（Java单引号是字符型），String是大写S。 |
| **整数** | int | `100` 、 `-5` | 直接写数字。另外还有 long（长整数）、short 等。 |
| **浮点数** | double | `3.14` 、 `0.5` | 默认带小数点的数字是 double。也可以用 float（需加 f 后缀）。 |
| **布尔值** | boolean | `true` 、 `false` | 全小写，用于逻辑判断。 |

---

### 三、条件判断（if / else if / else）

Java 用圆括号 `( )` 包裹条件，用大括号 `{ }` 包裹代码块（缩进只是美观，不起作用）。

```java
int score = 85;

if (score >= 90) {                    // 条件必须写在括号里
    System.out.println("优秀");       // 大括号里的代码属于if
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

// 【比较运算符】与Python完全一致：
// ==   !=   >   <   >=   <=
// 逻辑运算符: && (且)   || (或)   ! (非)
```

---

### 四、循环（for / while）

#### 1. for 循环（经典三段式）

```java
// 打印 0 到 4
for (int i = 0; i < 5; i++) {   // 声明变量 -> 条件判断 -> 步进操作
    System.out.println("当前数字: " + i);
}

// 增强型for循环（遍历数组/集合）
String[] fruits = {"苹果", "香蕉", "橙子"};
for (String fruit : fruits) {
    System.out.println("我喜欢吃 " + fruit);
}
```

#### 2. while 循环（与Python几乎一样）

```java
int count = 0;
while (count < 3) {
    System.out.println("循环中...");
    count = count + 1;          // 或者 count++;
}
```

---

### 五、函数（方法/Method）

Java 里的函数通常叫做方法，定义时必须指明返回值类型（如果没有返回值，写 `void`）。

```java
// 【定义方法】
// 访问修饰符 public  返回值类型 String  方法名 greet  参数 String name
public static String greet(String name) {
    String message = "你好，" + name;
    return message;             // 返回 String 类型
}

public static int add(int a, int b) {
    return a + b;               // 返回 int 类型
}

// 【调用方法】—— 必须在 main 方法（程序入口）里调用
public static void main(String[] args) {
    String result1 = greet("小红");
    System.out.println(result1);    // 输出: 你好，小红
    
    int result2 = add(5, 3);
    System.out.println(result2);    // 输出: 8
}
```

> 🔥 **Java 特色**：每个程序都必须有一个 `public static void main(String[] args)` 作为入口，否则程序无法启动。`void` 表示没有返回值。

## 核心差异一览表（对照记忆）

| 维度 | Python | Java |
| :--- | :--- | :--- |
| **变量类型** | 动态类型（变量可随时改变类型）。 | 静态类型（声明后类型固定，不可变）。 |
| **代码块标识** | 缩进（强制！缩进错了程序就崩）。 | 大括号 `{}`（缩进只为了美观，编译器不看）。 |
| **语句结束符** | 换行（一行就是一句）。 | 分号 `;`（每条语句必须以分号结尾）。 |
| **布尔值写法** | `True` / `False`（首字母大写）。 | `true` / `false`（全小写）。 |
| **字符串引号** | 单引号 `'` 或双引号 `"` 都可以。 | 双引号 `"` 表示字符串；单引号 `'` 表示单个字符。 |
| **函数/方法入口** | 文件从上到下执行，推荐写 `if __name__ == "__main__":` 控制。 | 必须写 `public static void main(String[] args)`，否则跑不起来。 |
| **逻辑运算符** | `and` 、 `or` 、 `not`（英文单词）。 | `&&` 、 `||` 、 `!`（符号）。 |

## 实战眼力测试：你能同时看懂这两段代码吗？

**题目**：判断年龄是否成年，并计算列表数字之和。

**Python 实现：**

```python
# 判断成年
age = 20
if age >= 18:
    print("已成年")
else:
    print("未成年")

# 计算列表和
numbers = [1, 2, 3, 4, 5]
total = 0
for num in numbers:
    total = total + num
print(f"总和是: {total}")
```

**Java 实现：**

```java
public class Test {
    public static void main(String[] args) {
        // 判断成年
        int age = 20;
        if (age >= 18) {
            System.out.println("已成年");
        } else {
            System.out.println("未成年");
        }

        // 计算数组和
        int[] numbers = {1, 2, 3, 4, 5};
        int total = 0;
        for (int num : numbers) {
            total = total + num;
        }
        System.out.println("总和是: " + total);
    }
}
```

> 请对比观察：Python 缩进 vs Java 大括号；Python 直接 `print` vs Java `System.out.println`；Python f-string 格式化 vs Java 加号拼接。逻辑骨架完全一致，只是“皮囊”不同！

## 写在最后：选哪门？还是都学？

* 如果你更偏向**数据分析、人工智能、自动化脚本、快速原型开发** -> 优先精通 **Python**。它的语法最接近人类思维，能让你专注于逻辑本身。
* 如果你更偏向**大型企业级后端、高并发系统、安卓开发** -> 优先精通 **Java**。它的静态类型和严谨规范能帮你打下坚实的工程化基础。
* 长远来看：**两门语言都值得掌握**。底层思维（变量、判断、循环、函数）互通，学会了一门，切换另一门只需要适应“缩进 vs 大括号”以及“动态 vs 静态”这两个核心差异即可。

**学习建议**：今天先只盯着其中一门语言（比如 Python）的代码示例，反复读 10 遍，直到能闭眼默写。下周再切换到 Java 看同样的逻辑。当你发现除了符号不同，思路完全一样时，你就真正“开窍”了。
